# 🛒 QKart Automation Testing (Selenium)

## 📌 Project Overview

This project focuses on automating end-to-end test scenarios for the QKart e-commerce application using Selenium WebDriver. It validates key user flows such as login, product search, cart operations, and checkout.

---

## 🚀 Tech Stack

* **Language:** Java
* **Automation Tool:** Selenium WebDriver
* **Test Framework:** TestNG
* **Build Tool:** Maven
* **Design Pattern:** Page Object Model (POM)

---

## ✅ Key Features

* Automated end-to-end user journeys
* Page Object Model implementation for better maintainability
* Reusable test utilities and functions
* Structured test execution using TestNG
* Maven-based project setup

---

## 🧪 Test Scenarios Covered

* User Login and Logout
* Product Search and Filtering
* Add to Cart functionality
* Cart Validation
* Checkout Process

---

## 📂 Project Structure

```
src/test/java    → Test scripts
src/main/java    → Page classes & utilities
testng.xml       → Test suite configuration
pom.xml          → Dependencies and build configuration
```

---

## ▶️ How to Run the Project

1. Clone the repository:

```
git clone https://github.com/ramzani77/qkart-automation.git
```

2. Navigate to project directory:

```
cd qkart-automation
```

3. Run tests using Maven:

```
mvn clean test
```

---

## 📊 Test Execution

* Tests are executed using TestNG
* Reports are generated in the `test-output` folder
